# CSE 325 - Team 11: Personal Finance Tracker

**Course:** CSE 325 - .NET Software Development
**Team:** Team 11 (solo, approved by instructor)
**Team Member:** Chibuike Collins Okolie

## Project Overview

A personal finance tracking web application built with .NET Blazor. The app
allows users to record income and expenses, organize transactions by
category, set monthly budget goals, and visualize their spending habits
through an interactive dashboard.

## Target Audience

Individuals who want a simple, straightforward way to track their personal
income and expenses and stay within a monthly budget, without the
complexity of full accounting software.

## Planned Features

- User authentication (register/login)
- CRUD functionality for transactions (income and expenses)
- CRUD functionality for categories (e.g., Groceries, Rent, Entertainment)
- Monthly budget goals per category
- Dashboard with spending summaries and charts
- CSV export of transaction history
- Responsive design for mobile and desktop
